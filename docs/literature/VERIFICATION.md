# Literature verification (2026-11-13)

Method. Bibliographic record: Crossref `/works/<doi>` (all DOIs below resolved; fields compared with the request). Retraction/correction: Crossref `updated-by`/`update-to` (empty for every item except as noted), OpenAlex `is_retracted` (false for every item; OpenAlex ingests Retraction Watch), Europe PMC `commentCorrectionList` and pubType. I could not query the Retraction Watch database UI itself; treat "no retraction" as "no flag in Crossref/OpenAlex/EuropePMC". Text: Europe PMC abstracts; PMC XML via NCBI efetch (author manuscripts count as full text); arXiv PDF; GitHub API.

Tags: [OPENED-FULL] = full text read for that claim; [OPENED-ABSTRACT] = abstract only; [NOT VERIFIED] = not opened, do not rely on it.
Quotes are <=25 words, from the opened text.

## Corrections to the request
- Mainland et al. 2015 is in **Scientific Data** 2:150002 (not Nat Neurosci). 73 odorants x 511 ORs.
- Lalis M2OR: **Nucleic Acids Res 52(D1):D1370** (published online Oct 2023; the "2024" is the issue year).
- Lee 2023 does **not** predict pleasantness or mixtures (text contains no "pleasant"); see METHODS.
- Arshamian abstract says 225 participants; the PMC author manuscript says 235. Cite the published abstract (225) and flag.
- Ma 2020 "model" = Ma, Tang, Thomas-Danguin, Xu, Chem Senses 45:303 (not a separate 2020 paper from a different group). Data paper = Data in Brief 36:107143 (doi 10.1016/j.dib.2021.107143), Dataverse DOI 10.15454/51OVY6 resolves in DataCite to the same title.
- Tom et al. / Sisson et al. mixture follow-ups: **not found** in Crossref/EuropePMC/bioRxiv searches; not included. Closest verified: Pellegrino 2025 (preprint), AtomFormer 2026 (preprint).
